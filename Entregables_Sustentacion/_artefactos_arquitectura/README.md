# Artefactos de arquitectura de AdMind

Fuentes de las dos páginas publicadas como Artifact el 22-nov-2026, para estudiar la sustentación:

- `arquitectura.html` → https://claude.ai/artifact/AtvFRZoD7oBgqei1JWTgip (Arquitectura de AdMind)
- `produccion.html` → https://claude.ai/artifact/QhrGRo5HGwQ3qK122vsgQJ (AdMind en producción)

Se editan las piezas con guion bajo (`_estilo.css`, `_comun.js`, `_<página>.cabeza.html`, `_<página>.cuerpo.html`) y se arma con:

```bash
./construir.sh https://claude.ai/artifact/AtvFRZoD7oBgqei1JWTgip https://claude.ai/artifact/QhrGRo5HGwQ3qK122vsgQJ
```
