## Como correr la app local:

Los dos. Son **dos servidores y cada uno necesita su propia terminal abierta**: el front recibe tu navegador y le pide los datos al backend. Si solo corres el front, el login responde "No hay conexión con el servidor de AdMind".

**Terminal 1, el backend (puerto 8000).** Enciéndelo primero.

cd "/c/Users/Alejandro/Documents/A D M I N D/Backend/Admind_Backend"

source .venv/Scripts/activate

python manage.py runserver 8000

**Terminal 2, el front (puerto 8001).**

cd "/c/Users/Alejandro/Documents/A D M I N D/Frontend/Admind_Front-End"

source .venv/Scripts/activate

python manage.py runserver 8001

Después abres `http://localhost:8001` y entras con el usuario de prueba. Deja las dos terminales abiertas mientras uses la app.

**Tres cosas que pueden fallar:**

- **Olvidar el `8001` en el front.** `runserver` usa el 8000 por defecto, que ya ocupa el backend, y el front espera la API justo ahí: así lo dice `ADMIND_API_URL` en su `.env`.
- **Abrir `localhost:8000` en el navegador.** Ves un "Not Found": es la API, no tiene pantallas.
- **"Error: That port is already in use".** Probablemente siguen vivos los servidores que levanté en el panel de vista previa. Ciérralos desde ese panel, o si siguen funcionando, entra directo a `localhost:8001` sin correr nada. Desde este chat no puedo comprobar si siguen encendidos
